1. What is the purpose of a README file?
A README file explains what a project is about, how to install or run it, and how to use or contribute to it. It helps developers understand the project and get started.

1. What is the purpose of a wireframe?
A wireframe is a basic visual outline of a website or application. It shows the layout and placement of elements, such as buttons, images, and text, before the design and development begin.
